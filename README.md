## 文件说明

- `history/`：供阅读的完整开奖记录，每期按“期号（开奖日期）：号码”显示。
- `draw_history.json`：程序读取的完整期号、开奖日期、号码与核对来源。
- `ls.json`、`ssq_history.csv`、`dlt_history.csv`：选号数据，记录标识也包含期号与日期。
- 不保存投注方案、生成时间、账号或Token；投注方案的生成时间仅保存在工作台。
